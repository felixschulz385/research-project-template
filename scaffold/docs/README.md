# Documentation

The docs are organised by line of work ([`lines/`](lines/)), plus the data-source pages
([`data/`](data/README.md)) and the design records ([`design/`](design/)). How it works, and
the rules: [`conventions.md`](conventions.md). Every table below is generated by
`python scripts/docs.py index` from the docs' own metadata; don't edit the tables by hand.

## Where to start

- **What each line of work asks and where it stands:** the table below, then the line's charter.
- **What a dataset is:** [`data/README.md`](data/README.md), then the source's page.
- **How the pipeline is built:** [`design/00-overview.md`](design/00-overview.md).
- **Starting something new:** a line (`python scripts/docs.py new line <slug>`), a pre-spec
  (`new prespec <slug> <step>`), a data page (`new source <key>`), a design record
  (`new design <topic>`). Ideas not yet started: [`ideas.md`](ideas.md).
